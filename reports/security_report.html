SSH Brute Force Attack 2

SSH Brute Force Attack 2026-02-15 09:30:12
IP Origem: 203.0.113.10
IP Destino: 10.0.0.5
Protocolo: TCP
Descrição: Múltiplas tentativas de login falhadas na porta SSH (22)
Detalhes: 3 tentativas em 60s

Metodologia de Mitigação

  • Prevenção: Implementar rate-limiting (max 5 tentativas/min), Utilizar autenticação por chaves SSH, Alterar porta padrão do SSH (22 → porta não padrão)
  • Deteção: Monitorizar logs de autenticação para múltiplas falhas, Alertas baseados em threshold por IP, Correlacionar tentativas no tempo
  • Resposta: Bloqueio temporário do IP ofensor (firewall), Adicionar IP a lista de reputação interna, Notificar equipa de segurança

Tentativa de Exploração SMB 1

Tentativa de Exploração SMB 2026-02-15 09:30:38
IP Origem: 185.130.5.10
IP Destino: 10.0.0.7
Protocolo: TCP
Descrição: Tentativa de acesso à porta SMB (445) de fonte externa
Detalhes: Possível exploração de vulnerabilidades Windows

Metodologia de Mitigação

  • Prevenção: Manter sistemas Windows atualizados (patches), Desativar SMBv1 e versões vulneráveis, Restringir acesso SMB a IPs internos apenas
  • Deteção: Monitorizar tentativas de conexão SMB externas, Detetar padrões de exploração conhecidos (EternalBlue), Analisar pacotes SMB malformados
  • Resposta: Bloquear IP de origem imediatamente, Verificar sistemas internos na mesma sub-rede, Verificar se houve execução de código remoto

Descrição: Tráfego NetBIOS de IP externo
Detalhes: Protocolo legacy exposto na borda da rede
